# Wayfinder

Use only when one implementation outcome cannot yet be named. The input is a fixed
destination and any known constraints. Inspect enough evidence to identify the major
decisions and dependencies, then finish with a bounded decision map and one explicit
next action. Do not start research agents, recurse, create tickets, or implement.
Each subsequent step requires a new explicit user invocation.
