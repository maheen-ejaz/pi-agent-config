# Skill provenance

This repository owns independent Pi-facing copies of every skill it ships. They do not load content from Codex or Claude Code configuration at runtime.

Ten initial Pi copies were derived from the public [`maheen-ejaz/agents-config`](https://github.com/maheen-ejaz/agents-config) repository at commit `17451626401a1bd70916b31f24b7b36cd83b6bee`, then adapted for Pi invocation syntax:

- `bb-cli`
- `diagnosing-bugs`
- `diagram-design`
- `grilling`
- `i-have-adhd`
- `repo-audit`
- `resolving-merge-conflicts`
- `tdd`
- `wayfinder`
- `writing-for-agents`

`linear-ticket-delivery`, `linear-ticket-operations`, and `infisical-credential-access` are Pi-owned workflows. Future edits are independent; copy changes across agent repositories only through deliberate review.
